About the Classifier

This system processes input strings through a TF-IDF Vectorizer to generate numerical word n-gram features. It feeds these outputs to a Multi-Output Logistic Regression Classifier. The backend classifies inputs across six categories: toxic, severe toxic, obscene, threat, insult, and identity hate.
